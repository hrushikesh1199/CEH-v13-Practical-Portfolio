# Disclaimer & Ethical Use Statement

This repository is a **personal educational portfolio** documenting completion of the EC-Council Certified Ethical Hacker (CEH) v13 certification program.

## Scope of Content
- All labs referenced were performed within **EC-Council's official CEH iLabs cyber range**, an isolated, sandboxed environment provided for certification training, against target systems the trainee was explicitly authorized to test.
- This repository contains **documentation, standard tool command syntax, and conceptual explanations** — it does **not** contain functional malware, weaponized exploit chains, or ready-to-run attack automation.
- Any "payload" examples shown are minimal, industry-standard test strings widely published in vendor documentation (e.g., OWASP, tool manuals) used purely to illustrate a vulnerability class for defensive understanding.

## Authorized Use Only
Every technique described in this repository must **only** be performed:
1. On systems you own, or
2. On systems for which you have **explicit, written authorization** to test, or
3. Within a legally sanctioned training/lab environment.

Unauthorized access to computer systems is illegal under laws including (but not limited to) the Computer Fraud and Abuse Act (US), the Computer Misuse Act (UK), and the Information Technology Act, 2000 (India). The author accepts no responsibility for misuse of the information contained in this repository.

## Purpose
This project exists to demonstrate applied knowledge of offensive security concepts and, equally, the corresponding **defensive/mitigation controls** for each technique — reflecting a professional, responsible-disclosure-minded approach to cybersecurity practice.
