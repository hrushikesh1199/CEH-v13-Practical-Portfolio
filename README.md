## About This Project

This repository documents my hands-on completion of all **20 modules** of the **EC-Council Certified Ethical Hacker (CEH) v13** program, covering the full offensive security lifecycle — from reconnaissance through exploitation, and closing with cryptography and cloud security. It is structured as a professional reference and portfolio artifact for cybersecurity roles (SOC Analyst, VAPT/Pentest, AppSec).

Each module folder contains:
- **Overview & Learning Objectives**
- **Labs Completed** (mapped to official CEH v13 lab guide)
- **Tools & Technologies** used
- **Key Commands / Techniques** (industry-standard syntax)
- **Sample Payloads / Test Strings** (where applicable, non-weaponized)
- **Detection & Mitigation** guidance (defensive counter-measures for every offensive technique)
- **Key Definitions** (glossary-style)
- **References / Sources**

> ⚠️ **Ethical & Legal Notice:** All techniques documented here were performed exclusively within EC-Council's official, isolated **CEH iLabs cyber range** against consenting lab infrastructure, strictly for certification and educational purposes. This repository is a **knowledge/documentation artifact** — it does not contain live exploit code, malware binaries, or attack automation intended for unauthorized use. See [`disclaimer.md`](disclaimer.md).
